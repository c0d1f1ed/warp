Pack Warp array subclasses through their native descriptors, preserving gradient
pointers and flags and applying the parent's family, dtype, and dimensionality
validation. Honor `retain_grad` and the parent's overwrite behavior, which can
change Tape gradients for overwritten outputs and in-place writes. Use native
storage instead of inherited or overridden array interfaces, and accept native
struct and `bfloat16` dtypes. Apply the parent's launch-access mode: the default
`RELAXED` mode remains unchecked, `CHECKED` diagnoses inaccessible or unverified
cross-device memory, and `STRICT` requires the launch device. Replace implicit
dtype or shape reinterpretation with an explicit `view()`, `reshape()`, or
`flatten()`, or convert element values into a correctly typed Warp array with
`warp.utils.array_cast()`. A separate non-Warp array-interface provider retains
the external-interface path. Reject incompatible descriptor overrides and
ambiguous inheritance between native array families. See the
[array subclass guide](https://nvidia.github.io/warp/user_guide/basics.html#array-subclasses)
for the input contract and family-specific capabilities.
